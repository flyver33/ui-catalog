# Справочник типов составных

> Машинная версия — `scripts/lib/composites.mjs`; при расхождении верна она, и selftest
> держит их вместе: типы, колонка «Виды», ложные срабатывания — дословно, как их можно
> писать в причине отказа. Как агент работает с типами — [composites.md](composites.md).

Составное — закономерность из атомов, которая повторяется в продукте больше одного раза
по смыслу. У каждого типа: **анатомия** (слоты; обязательные — жирным), **виды**,
**признаки** (по ним скрипт находит экземпляры, даже если разметка каждый раз своя) и
**ложные срабатывания**. Атомы (кнопка, поле формы, переключатель, вкладки…) — не здесь,
а в [types.md](types.md): это кит.

## Всплывающие (`family: overlay`)

Всё всплывающее — составное (решение автора, 2026-10-09).

| Тип | Анатомия | Виды | Признаки |
|---|---|---|---|
| `dialog` — Dialog | **title**, **body**, actions, **close**; затемнение — часть окна | confirm, form, announce, info, picker, filters, auth, flow, survey | `Modal`, `role="dialog"`, оверлей; имя `*Modal`, `*Dialog` |
| `bottom-sheet` — Bottom sheet | шторка снизу, **body**, actions | — | прижато к низу экрана, затемняет; на телефоне |
| `popover` — Popover | триггер + **панель** с выбором или действием | — | открывается по клику у элемента, не затемняет |
| `tooltip` — Tooltip | триггер (иконка «?»/«i», обрезанный текст, выключенная кнопка) + **текст**: подсказка, почему недоступно, полный текст | — | `Tooltip`, `title=`, `aria-describedby` |
| `toast` — Toast | icon, **text**, action, close; исчезает сам | success, error, info | сервис уведомлений, таймер, позиция поверх страницы |

Виды Dialog: `confirm` — текст и два действия, опасное — тоном; `form` — поля и submit;
`announce` — картинка, текст, один CTA, иногда «больше не показывать»; `info` — длинный
текст и close; `picker` — поиск и список с выбором; `filters` — фильтры или сортировка в
окне; `auth` — вход и регистрация; `flow` — несколько шагов; `survey` — опрос.

Ложные срабатывания: «выпадающий список селекта» — часть атома Select, не Popover;
«баннер без таймера» — это Banner, не Toast.

## Блоки страницы

Колонка «Виды» здесь и выше — ровно то, что можно записать в `kinds:`.

| Тип | Анатомия | Виды | Признаки |
|---|---|---|---|
| `snippet` — Snippet | media, **title**, meta, status, actions, ссылка на сущность; сущность — в `entity`, бывает full и compact | — | повтор внутри `.map(…)`; одна форма дерева; имя `*Card` |
| `list-item` — List item | leading, **primary**, secondary, trailing | — | однородные строки внутри блока |
| `section` — Section | **title**, description, actions, **body** | — | повторяемая анатомия заголовка блока; имя `*Section` — подсказка |
| `page-header` — Page header | breadcrumbs, **title**, meta, actions | — | первый блок страницы с заголовком |
| `app-header` — App header | **logo**, nav, actions, user; у кабинета, лендинга и мобильной — свои экземпляры | — | шапка над всеми страницами раздела |
| `app-footer` — App footer | группы ссылок, юридическое, соцсети | — | подвал над всеми страницами |
| `banner` — Banner | icon, **text**, action, close | promo, status, info, warning | полоса с сообщением в странице или списке |
| `form` — Form | **поля** (атом «поле формы»), **действия**; в странице или по шагам — форма в окне это Dialog `form` | — | `form`, submit |
| `filters` — Filters | **группы полей**, выбранные значения чипами, применить / сбросить; сбоку или полосой — в окне это Dialog `filters` | — | состояние фильтров, «сбросить» |
| `table` — Table | **заголовки**, **строки**, сортировка, пагинация | — | `table` или сетка однородных строк с заголовками |

Ложные срабатывания: «нет повторяемой анатомии» — часть страницы без неё, не Section;
строка внутри сниппета — List item, а не второй Snippet (причина отказа — «часть
составного snippet»).

## Неочевидные — обычно сделаны вёрсткой на месте

Разработчики не переиспользуют такие блоки и не считают их компонентом, поэтому по
одинаковой разметке их не найти — только по признакам смысла.

| Тип | Анатомия | Признаки смысла | Ложные срабатывания |
|---|---|---|---|
| `empty-state` — Empty state: first-use / no-results / error | media, **title**, text, action | ветка `!items.length`, `length === 0`, `isEmpty`; ключи `empty*`, `notFound*`, `noResults*`; «пока нет», «ничего не найдено», «не удалось»; действие «создать», «сбросить фильтры», «повторить» | «ошибка валидации поля» («Название не может быть пустым») |
| `loading-state` — Loading state | заглушки по форме контента или спиннер на месте блока | ветка `isLoading`, `isPending`, `isFetching`; `Spinner` / `Loader` вместо контента | «спиннер в кнопке» — состояние кнопки |
| `error-state` — Error state | icon, **title**, text, retry | ветка `error`, `isError`; `refetch` / `retry`; «ошибка», «попробуйте позже» | — |
| `success-state` — Success state | icon, **title**, text, следующий шаг | ветка `isSuccess`, `submitted`; ключи `*Success*`; «Спасибо», «Отправили» | «тост об успехе» — это Toast |
| `show-more` — Show more: «+N», «Показать ещё», «Свернуть» | видимые элементы, **счётчик или переключатель** | `slice(0, n)` + остаток; «ещё», «показать все», «свернуть» | «пагинация» — это атом |
| `status-label` — Status label | точка или плашка + **текст статуса** | словарь статусов сущности (`status` → цвет и текст) на нескольких страницах | «Tag без статуса» |
| `key-value` — Key–value list | пары **подпись — значение** | `dl`/`dt`/`dd` или повторяющиеся пары в профиле, вакансии | — |
| `stat-tile` — Stat tile | **число**, подпись, динамика | крупное число + подпись, повтор в ряд | — |
| `paywall` — Paywall | что закрыто, почему, **действие** «подключить» / «купить» | проверка тарифа или лимита (`hasAccess`, `limit`), CTA на тарифы | — |
| `copy-field` — Copy field | **значение**, **кнопка «скопировать»**, подтверждение | `navigator.clipboard`, «Скопировано» | — |
| `sticky-actions` — Sticky actions | панель **действий** у нижнего края | `position: sticky` / `fixed` снизу с кнопками | «шапка» — это App header |
| `onboarding-hint` — Onboarding hint | метка «новое» или подсказка к функции, «больше не показывать» | флаг «показано» в хранилище; ключи `*Intro*`, `*New*` | «анонс в окне» — это Dialog `announce` |
| `social-links` — Social links | ряд **иконок-ссылок** на профили | ссылки на внешние домены (github, linkedin, telegram) с иконками | — |

## Продуктовые блоки

Продуктовый блок — экземпляр общего типа с именем из предметной области: `CriterionCard`
(карточка критерия в ИИ-разборе) — Snippet, `CriteriaSummaryPanel` — Section. Если ни
один тип не подходит, это тип проекта (`type: project`, [[pat.project-type]]): он
описывается полностью и идёт в отчёт кандидатом сюда.

Составные вкладываются: сниппет кандидата → строки опыта (List item) → ряд соцсетей
(Social links). Раздел «Состав» описания показывает, что в каком слоте.

Новый тип добавляется сюда и в `lib/composites.mjs` вместе с признаками и ложными
срабатываниями.
