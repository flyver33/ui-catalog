# Тест-кейсы собранного каталога: галерея

Что должно быть верно в галерее любого каталога, собранного `build`; примеры — по
[examples.md](examples.md). Кейсы **A** проверяет раннер `gallery/selftest.js`: его запускает
`node scripts/gallery-test.mjs` (правила — в конце файла), он обходит все страницы и пишет
итог в `gallery/selftest.json`. Кейсы **V** смотрятся глазами по скриншотам — их раннер
проверить не может.

Без браузера на машине открой `gallery/index.html?selftest` в своём, с уникальным параметром
(`?selftest&1`, `&2`…): у `index.html` нет хэша в адресе, и статический сервер отдаёт старую
копию. Итог — внизу страницы и в `window.__uicSelftest`.

Каталог готов, когда `check` без ошибок, `?selftest` без провалов и пройдены кейсы V.

## Running the A cases

- **gal.selftest-run** (script: gallery-test.mjs#findBrowser, selftest.js) — `node scripts/gallery-test.mjs` runs `?selftest` with
  no agent: it serves, on 127.0.0.1 and a free port, the nearest folder holding the
  library and every file the gallery links to (nothing outside it), starts a Chromium
  browser found on the machine — `UI_CATALOG_BROWSER`, else Chrome, Edge or Chromium in
  their usual places — headless, 1280×900, with a throwaway profile, and opens
  `gallery/index.html?selftest&report`; when the walk is done the page posts its result
  to that server. The result is `gallery/selftest.json`: the hash of the `data.js` it
  ran on, the date, the browser, pages, checks, failures. Exit 0 without failures, 1
  with; no `data.js` or no browser — it says so, writes nothing, exit 2. A walk not done
  in 10 minutes is a failure G01 «прогон не закончился». The agent's own browser stays
  the way to look at V cases, and the fallback for A when no browser is found.
- **gal.selftest-seen** (check) — `check` reads `gallery/selftest.json` next to a built
  gallery: each failure of a run on the current `data.js` is an error, its case id and
  page in the message; no run, or a run on another `data.js` (a later `build`), is a
  warning «галерею не проверяли» naming the command.
- **gal.frames-failed** (check) — `check` reads the frames `build` could not draw
  (`components.json` → `failedFrames`, a React gallery) and warns once per atom or
  composite: how many of its frames say «не отрисовался» and why, the reasons as the
  frames say them; `--report` gives the user the count by reason. A warning, not an
  error: what such a frame lacks is the project's data or a browser, not something the
  agent may write into the project (decision of the author, 2026-10-13).
