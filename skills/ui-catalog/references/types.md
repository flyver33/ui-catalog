# Справочник эталонных типов

Каждому атому в библиотеке ставится тип: `type: button` во front matter. По типу
`audit.mjs` знает, какие состояния у компонента обязательны и какие модификаторы обычно
оказываются заплатками. Машинная версия справочника — `scripts/lib/types.mjs`; при
расхождении верна она.

Справочник собран по WAI-ARIA APG, Material 3, HIG и распространённым китам. Это не
таксономия «на всё», а минимум, по которому видно пропуски и заплатки.

Тип задаёт и **название компонента**, если у проекта нет своего кита: `button` →
Button, `chip` → Chip, `nav-item` → Menu item. Названия английские, как в Figma и в
большинстве китов; текст гайдлайнов — на языке проекта. Машинная версия — поле `name`
в `lib/types.mjs`. Порядок выбора названия и что делать, если тип не подошёл, — [[gl.name]] в
[guideline.md](guideline.md).

| Тип | Название | Роль | Интерактивный | Обязательные состояния | Обычные оси |
|---|---|---|---|---|---|
| `button` | Button | button | да | hover, нажато, фокус, выключено | вид, заливка/обводка, тон, размер, ширина |
| `icon-button` | Icon button | button | да | hover, нажато, фокус, выключено | вид, размер |
| `link` | Link | link | да | hover, фокус | — |
| `tag` | Tag | текст | нет | — | тон, размер |
| `chip` | Chip | button (checkbox, если выбирается) | да | hover, фокус | тон, размер |
| `badge` | Badge | текст / status | нет | — | тон |
| `avatar` | Avatar | img или button | бывает и так, и так | hover, фокус — если кликабельный | размер |
| `logo` | Logo | link | да | фокус | — |
| `icon` | Icon | img, `aria-hidden` | нет | — | размер |
| `select` | Select | combobox | да | hover, фокус, раскрыто, выключено | размер, ширина |
| `autocomplete` | Autocomplete | combobox: поле ввода + listbox | да | hover, фокус, раскрыто, выключено, ошибка | размер, ширина |
| `input` | Input | textbox | да | hover, фокус, выключено, ошибка, только чтение | размер, ширина |
| `textarea` | Textarea | textbox (многострочное) | да | hover, фокус, выключено, ошибка | размер, ширина |
| `form-field` | Form field | подпись + поле + подсказка + ошибка | да | ошибка, выключено | — |
| `checkbox` | Checkbox | checkbox | да | hover, фокус, отмечено, частично, выключено | — |
| `radio` | Radio button | radio | да | hover, фокус, отмечено, выключено | — |
| `switch` | Switch | switch | да | hover, фокус, отмечено, выключено | — |
| `tab` | Tab | tab | да | hover, фокус, выбрано | — |
| `nav-item` | Menu item | link + `aria-current` | да | hover, фокус, текущее | — |
| `breadcrumb` | Breadcrumbs | navigation | да | hover, фокус, текущее | — |
| `list-item` | List item | listitem / option | бывает и так, и так | hover, фокус, выбрано | — |
| `progress` | Progress bar | progressbar | нет | — | размер |
| `pagination` | Pagination | navigation | да | hover, фокус, текущее, выключено | размер |
| `spinner` | Spinner | status | нет | — | размер |
| `divider` | Divider | separator | нет | — | — |

**Tag и Chip — два типа, а не один тип в двух видах.** Tag только показывает
свойство и никогда не реагирует на наведение. Chip — кликабельный: фильтр, выбор,
«+N». Когда в коде Chip — модификатор того же класса, его отделяет скрипт: [[comp.split]],
[[comp.split-type]] в [components.md](components.md).

### Всплывающие элементы (`family: overlay`)

> В React-проекте (режим кита) всё всплывающее — составные, а не атомы кита: см.
> [composite-types.md](composite-types.md). Таблица ниже — для каталога HTML/CSS.

Всё, что появляется поверх страницы. Типы разные, потому что разное поведение: одни
затемняют экран и требуют ответа, другие появляются у элемента или исчезают сами.

| Тип | Название | Что это | Затемняет экран |
|---|---|---|---|
| `dialog` | Dialog | окно по центру экрана с действием, часто с формой | да |
| `progress-dialog` | Progress dialog | отдельное окно, пока что-то долго грузится | да |
| `bottom-sheet` | Bottom sheet | шторка снизу экрана на телефоне | да |
| `popover` | Popover | появляется у элемента, в нём выбирают или делают действие | нет |
| `tooltip` | Tooltip | короткая подсказка у элемента, без действий | нет |
| `toast` | Toast | временное сообщение, исчезает само | нет |

**Уведомления ОС — не тип.** Их рисует система, а не CSS проекта, в кодовой базе их нет.
Окно «Мы обновили условия» — это Dialog.

**Затемнение (scrim) — не тип и не компонент.** Само по себе оно ничего не значит:
это часть Dialog, Bottom sheet и Progress dialog. Если в коде затемнение — отдельный
класс, общий для нескольких окон, он идёт в `scaffold` одной строкой («затемнение под
Dialog и Bottom sheet»), а в описании каждого окна — в «Как собрать».

## Признаки заплаток («не ось»)

Признак — это **повод для строки в отчёте несостыковок** (`ui-issues.md`), а не вердикт.
Каждый проверяется фактом, и у
каждого есть законное исключение.

| Тип | Признак | Как проверить | Когда законно |
|---|---|---|---|
| button | `inherit` / `ghost` / `plain` / `default` / `light` | ΔE < 1 к соседнему виду на всех фонах, или отличие только в псевдосостояниях | Tertiary, если заметно отличается (ΔE ≥ 5) и нужна для низкого акцента (text button в Material) |
| button | цветовой модификатор под одну страницу | использован один раз | статусная кнопка (опасное действие) с понятным смыслом |
| icon-button | голый `<button>` с иконкой | повторяется в двух местах и больше | единственное место (бургер в шапке) |
| tag | `nohover` / `static` / `readonly` | модификатор только отменяет `:hover` | никогда: у Tag hover не бывает, кликабельное — это Chip |
| chip | цвет только у кликабельных | модификатор только на `<button>`, база — и на `<span>` | тон со своим смыслом, совпавший случайно |
| nav-item | `--active` без `aria-current` | текущее только классом | класс допустим, если рядом ставится `aria-current` |

Новый тип добавляется в оба файла с обоснованием. Если у компонента нет подходящего
типа, `type` не ставится, а название своё: `check` пишет об этом «к сведению».
