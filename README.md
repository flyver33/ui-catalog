# ui-catalog

Плагин Claude Code из двух скиллов. Один превращает кодовую базу в библиотеку компонентов, другой собирает из этой библиотеки фичи.

| Скилл | Когда | Что делает |
|---|---|---|
| **ui-catalog** | редко: первая настройка, новый компонент, после крупных правок | Разбирает код на компоненты. Пишет гайдлайн к каждому: задача, когда брать и когда нет, варианты, состояния, показательные места с `file:line`. Собирает из кода основы — роли цветов, шкалу текста, отступы, анимацию, иконки, каркас, — `CATALOG.md` для агентов и HTML-галерею для людей. |
| **ui-compose** | часто, на каждой UI-задаче | Разбивает задачу на UI-задачки и подбирает под каждую компонент. Собирает то, что покрыто библиотекой. Для недостающего пишет запрос дизайнеру в `requests/`. |

```
код → scan → компоненты → гайдлайны + состояния → build → check → галерея
                                                     ↓
задача → ui-compose → собрано из библиотеки  +  requests/<фича>.md → дизайнер → ui-catalog add
```

## Установка

```bash
claude plugin marketplace add flyver33/ui-catalog
```

```bash
claude plugin install ui-catalog@ui-catalog
```

Дальше в проекте скажите агенту «собери каталог компонентов» — он запустит `ui-catalog`. На UI-задачах `ui-compose` включается сам.

## Что появляется в проекте

```
docs/design-system/
  catalog.config.json   настройки: стек, где база, где страницы и фичи
  atoms/<id>.md         описание атома (пишет агент)
  examples/<id>.html    все состояния компонента (из реальной разметки: факты пишет скрипт, остальное агент)
  requests/<фича>.md    чего не хватило фиче (пишет ui-compose)
  CATALOG.md            индекс для агентов: основы и компоненты (генерируется)
  foundations/          цвета по ролям, текст, форма, отступы, анимация, иконки, каркас (генерируется)
  components.json       машинный индекс (генерируется)
  gallery/index.html    галерея для людей (генерируется)
docs/ui-issues.md       несостыковки в коде, для чтения человеком (генерируется, вне каталога)
```

Каталог агент собирает целиком за один проход и ни о чём не спрашивает. Дальше каталог принадлежит проекту: меняйте его как хотите. Места, где код расходится сам с собой (hover у некликабельного, пропавший фокус, два почти одинаковых вида), каталог описывает как есть, а перечисляет их отдельный отчёт `ui-issues.md`: что не так, почему важно, где в коде, что можно сделать.

Галерея — статичный HTML, все примеры в ней рисуются с настоящими стилями проекта. Она устроена как иерархия: все компоненты → компонент → вид («Button → Primary»). На странице вида сверху живой пример, на него можно навести и нажать. Ниже вкладки:

- «Состояния» — статичные картинки: hover, нажатие, фокус, размеры;
- «Как использовать» — гайдлайн;
- «Где используется» — места со ссылками в редактор;
- «Код» — разметка, классы, токены.

Отдельно есть страницы токенов и иконок.

## Скрипты

Скрипты запускает агент; руками — так же. Все на Node 18+, без зависимостей; пути — от папки плагина, проект передаётся через `--root <проект>`.

```bash
node skills/ui-catalog/scripts/scan.mjs  --root <проект>   # инвентарь
node skills/ui-catalog/scripts/generate.mjs --root <проект> --all   # описания и примеры: факты из кода
node skills/ui-catalog/scripts/build.mjs --root <проект>   # CATALOG.md, foundations/, components.json, gallery/
node skills/ui-catalog/scripts/audit.mjs --root <проект>   # ui-issues.md — несостыковки
node skills/ui-catalog/scripts/check.mjs --root <проект>   # что разошлось с кодом; --seal all — печать; --report — отчёт
node skills/ui-catalog/scripts/gallery-test.mjs --root <проект>   # тест галереи в браузере без окна (Chrome, Edge или Chromium)
node skills/ui-compose/scripts/query.mjs search <слова задачи> --root <проект>
```

## Стеки

- `html-css` — статичная вёрстка и любые проекты, где компоненты — это семейства CSS-классов.
- `react` — React и TypeScript (TSX/JSX): вместо описаний компонентов — спеки атомов будущего кита по всем реализациям в коде, вопросы людям там, где код расходится сам с собой, и составные (окна, сниппеты, пустые состояния), найденные в коде. Галерея рисует реализации React проекта рядом.

Если стек не поддерживается, скан честно останавливается, а не выдаёт неправильный инвентарь. Подробности — [skills/ui-catalog/references/adapters.md](skills/ui-catalog/references/adapters.md).
